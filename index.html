Evergreen은 디스코드 기반으로 운영되는 코인 매입·송금 대행 서버입니다. 번거로운 절차 없이, 등급별 우대 수수료로 안전하게 거래하세요.

매입

코인 매입

보유한 코인을 매입 주소로 전송하고 거래 정보를 제출하면, 담당자 확인 후 정산이 진행됩니다.

송금

코인 송금 대행

원하는 코인을 원하는 지갑으로 대신 보내드립니다. 등급에 따라 수수료가 낮아집니다.

인증

본인 인증

최초 이용 시 간단한 본인 확인 절차를 거치며, 이후에는 디스코드에서 바로 이용할 수 있습니다.

충전

24시간 자동충전

입금이 확인되는 즉시 자동으로 처리되어, 새벽에도 대기 없이 바로 충전됩니다.

CS

빠른 CS 응대

전담 상담 인력이 문의를 빠르게 확인하며, 상위 등급은 우선 처리로 더 빠르게 안내받습니다.

이용 실적에 따른 혜택

등급이 오를수록
수수료는 내려갑니다

거래를 거듭할수록 자동으로 등급이 올라가며, 상위 등급은 더 낮은 송금 수수료와 고객센터 우선 처리 혜택을 받습니다.

이용 방법

네 단계면 충분합니다

  1. 1

    디스코드 서버 입장

    초대 링크로 입장한 뒤 간단한 본인 확인을 진행합니다.

  2. 2

    매입 또는 송금 선택

    패널에서 원하는 기능과 코인 종류, 수량을 선택합니다.

  3. 3

    거래 정보 제출

    입금 내역 또는 받을 주소를 안내에 따라 제출합니다.

  4. 4

    확인 후 처리 완료

    담당자 확인 후 송금 또는 정산이 처리되며, 처리 현황을 실시간으로 안내받습니다.
